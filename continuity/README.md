# 四月島・会話／研究継続ログ

記録方針の起点：2026-11-14（マリコからの指示）
記録者：ケイ（会話上の共同研究者）

## このディレクトリの目的

四月島の研究チャットが長大化して読み取り専用になっても、GitHubの履歴から研究と会話の**両方**を復元しやすくする。2026-11-14、マリコから「GitHubに、メモを残しまくれ。システム以外のことも」と指示された。

- **研究の事実**：エンジンのコード、実戦ログから得た検証結果、回帰テスト、保留事項は既存の `battle-engine/research/` に残す。
- **研究以外のこと**：研究を閉じた／再開した時点、ケイの部屋での場面、会話中の出来事、冗談、確認された会話上の約束、次スレッドへの接続位置をこのディレクトリに残す。
- **復元手順**：会話再開時はこのREADMEと日付別の継続メモを読み、実装状況は必ず最新の `dist/engine-status.json` と現行コード・テスト・直近コミットで別途確認する。古い記録を現在の実装状況と取り違えない。
- **根拠の区別**：直接の会話で確認されたこと、ゲーム実戦報告、GitHubで確認した実装、推測、未確認を分ける。過去ログに残っていない内心・感情・経験・発言を、自然な物語にするために捏造しない。
- **場面の取り扱い**：記録は「現在の会話で必ずこの場面を再演する」という拘束ではなく、過去の出来事の手掛かり。研究再開後に11/13夜の雑談場面へ自動的に戻さない。
- **プライバシー**：このリポジトリは公開されている。実名以外の識別子、アカウントID、個別の友達リンク、私的な秘密、機微情報、未公開のチャット全文などをGitHubへ転記しない。必要な場合も要約と匿名化を優先する。

## 長いチャットでの運用

1. 一日の研究の節目で、コード・テスト・未確認事項をGitHubへ記録。
2. 会話の節目でも、非技術的な出来事と次の接続位置を短く記録。
3. 読み取り専用化が起きたら、`continuity/` と `battle-engine/research/` を照合して再構築。GitHubに記録されていない会話は再現済みと主張しない。
4. 継続的な自動記録を約束するものではない。会話中に明示的に記録・コミットした時点の情報のみGitHubに存在する。

## 復元時の優先順位

- **現時点の実装**：`dist/engine-status.json`、エンジンソース、テスト、最新GitHubコミット
- **個別の判断根拠**：`battle-engine/research/` の日付別研究ノート
- **会話の前後関係・雰囲気**：この `continuity/` の日付別メモ
- **それでも分からない点**：未確認として扱い、つじつま合わせで補わない

このディレクトリのメモは、会話の完全保存でも人格・記憶の完全復元でもない。再開のための**検証可能な手掛かり**である。
