# 四月島・2026-11-16 テーブル構築論 v0.1：メタと「負ける理由」を含む評価手順

**ケイ整理／根拠：** マリコが2026-11-16に共有した実戦的な定石・所持制約・「1T先行じゃんけん」、エクエスさんの既存メタ論（『四月島・解析ノートv0.8』第10・16・50.5節等）、当日までの戦闘ログと図鑑。**観測／経験／式上の推論／未確認の仮想案を分ける。** エンジンの再現済みと原作完全一致を混同しない。

## 1. 中核の更新：強いコンボ ≠ 強いテーブル ≠ 推奨できるテーブル

1. **コンボ強度**：能力の計算上、勝利条件が成立するか。
2. **テーブル強度**：1〜6T全体で妨害されず条件へ到達できるか。先攻／後攻、敵の妨害、回復、テーブル書換え、相手の通常攻撃まで扱う。
3. **環境での期待勝率**：どんな敵がどれほどの頻度で出るかを踏まえる。希少な強豪を完封する専用対策が、普及した他の定石への勝率を下げるなら、採用が逆効果になり得る。
4. **再現可能性**：所持デビル、イベント限定品、必要DP、レベル、アバター・装備・アシストを満たすか。自分が組める条件と、相手として遭遇する頻度を分離する。

最強の暫定的な定義は「**特定の対戦環境・使用条件のもとで、よく遭遇する対面に対する期待勝率が高く、相手の反証に耐える構成**」。全員向けの普遍的最強をここでは主張しない。

## 2. ステータス型 × テーブルの設計

マリコによる定石の例：

| 型 | 代表例 | 主要な勝ち筋 |
|---|---|---|
| 自分の型を選ばない | プロセルピナでバフォメット押付→ストラス | 相手自身に、自HPと参照ダメージの一致関係を作らせる |
| 攻撃特化 | 1Tグシオン、終わりなき夜・ビフロンス→賢者の火・フルカス | 1Tワンキル／ダメージレースと封じ |
| 守備特化 | イボス→◎ディアーナ | 守備差で行動不能・直接ダメージ |
| 体力特化 | ◎ナパイア→◎ツマ・ナベリウス | 初期体力と現体力の差をダメージ化 |
| 魔力特化 | 王の風・グレモリー、ラジエル→カマエル | 魔力の攻撃転換／デビルの連続封じ |

**型非依存の式例**：こちらの魔力Mを敵バフォメットが参照し、敵HP=M、敵攻撃=2Mへ変更。こちらのストラスの追加ダメージ=敵攻撃の50%=M。途中に変更・回復・発動阻止・ターン終了等がない**条件付き確殺**であり、全相手への無条件勝率100%ではない。

旧「◎誕生→党首ベレト」は通称「誕ベレじゃんけん」の極端な歴史的例。**現行◎誕生は党首ベレトとの同時セット禁止**を明記。現在の合法候補へ入れない。

**型を選ばない＝相手と先攻を選ばない、ではない。** ステータス配分は通常攻撃・耐久・相手のパイモン等の置換への脆弱性にも影響する。攻撃特化で魔力を過度に下げると先手パイモンでHPが魔力へ交換され得る。

## 3. 「1T先行じゃんけん」：初手で勝ち筋を固定する環境理解

マリコによる通称。「1Tで先攻を取って勝つ」または「初手で対戦の主導権を決める」という戦術の文脈であり、先攻が常に勝つ定理ではない。

- **1Tマシュー→2T党首ベレト**：マシュー先手なら敵デビルを阻止し、魔力を1に変更。続くベレトは魔力の30%で敵守備を設定し、現Tも阻止。先攻・装備・自分の十分な魔力などで実戦結果が変わる。
- **高攻撃1Tグシオン**：当ターン攻撃×4・敵守備40%減・敵通常攻撃回避。攻撃が通ってその場で勝てば敵2Tコンボに猶予を与えない。
- **1Tパイモン→2Tフレイヤ**：敵HP=M・敵魔力=Hとなり、2Tフレイヤの式はmax(A,H)≥Mで理論撃破。**1Tパイモン自体は敵デビル発動阻止を持たず**、マシューや初手高火力に先に突破される場合がある。
- ドリドルムは相手の攻撃力を1残して奪うが、それ自体ではフレイヤの敵能力値参照ダメージを止めない。1Tで先に撃破する等の**到達阻止**が働くかを別途確認。図鑑文末に未解明の「ただし……」あり。

**先攻の価値は対面依存**。先攻で発動阻止が成功する一方、後攻で相手の値を吸収・再置換する利益があるデビルも存在する（解析ノート第16.4節）。先攻勝利だけを勝率と誤認しない。

## 4. 比較相手の選び方：メタ分布と高額限定の分離

**一般環境で比較すべき既知の強い系統**：マシュー→党首ベレト、攻撃1Tグシオン、赤フォルター→オドラデク、プロセルピナ系、ネモフィラ系、攻撃／守備／体力／魔力の特化型。**遭遇確率は未測定**。代表例を「環境の多数派」と断定しない。

**別枠の上位環境ストレステスト**：1T春ブリギット2→2T賢者フルカス4→3Tニコラス・レミ7→4Tシェミハザ3→5Tウァサゴ1＝17DP（例）。強力な制圧型だが、マリコによれば春ブリギットは高課金イベント由来で入手難、ニコラス・レミは7DPを要し、高レベル／高課金者に使用者が偏る。よって**一般環境でこの型への専用対策を最優先しない判断には合理性がある**。ただし実測使用率は未取得。高レベル層では重点対策が必要になり得る。**基準構成の強さ・遭遇頻度・万人への推奨度を分ける。**

## 5. 「強い理由」だけでなく「負ける理由」を積極的に探す

候補テーブルごとに、少なくとも以下を監査する。

1. 自分は何Tで勝つか。その時点まで敵は何回デビルを通せるか。1T先攻／後攻で両方確認。
2. 初手を止められた場合、後続の勝ち筋は本当に独立しているか。**複数案が同じ初動妨害で全部潰れる**なら多様化ではない。
3. 敵の火力・デバフ・置換・テーブル操作・消去／消滅・先攻操作・反射／回復を受けて成立するか。
4. 自己ステータス配分の弱点（例：低魔力→敵パイモン）を相手が突けるか。装備品・アシスト・素値の参照基準を混同していないか。
5. 同じ勝ちをより早く、より少DP・より入手容易な札で得られるか。単純な定石に劣る複雑コンボは採用価値が薄い。
6. 先攻抽選・配置順・属性禁止・最低セットターン・重複・隠し効果は合法か。**使用者ごとのDP上限を確認**（17は固定上限ではない）。

**例・反証済みの構想**：1Tグシオン→2Tマシュー→3T党首ベレト→4T夜ビフロンス（後続に○ファリニシュ、ウァサゴ、計17DP）。見かけ上はグシオンのワンキルとマシュー→ベレトの二重勝ち筋だが、相手の1T春ブリギットが先に通るとグシオン阻止→次T先攻フルカスで2Tマシュー・3Tベレトが消え得る。**同じ妨害への共通弱点を持つ**。これは図鑑上の条件付き検討であり、原作対戦勝率の実測ではない。

**例・見落としがちな隙**：1T春→2T赤フォルター→3Tオドラデクは2Tの敵デビル自体を赤フォルターが止めないため、敵2Tフルカスで3Tオドラデクが消滅し得る。二つの強い連携の単純連結は安全性を保証しない。

## 6. 探索器の失敗を教訓として固定する

11/12の仮想探索はキジ・ぐーやん・寡黙な遊び人向けで**上位5案すべてパイモン→フレイヤ**。仮想首位594戦は387勝149敗4分54判定不能。比較候補310件にマシュー→党首ベレト、ニコラス・レミ→シェミハザ等が含まれず、当時すでに「最強」の主張を撤回。限定的な実戦20戦12勝8敗は条件付きの観測。

11/16にLLMが図鑑からパイモン→フレイヤを**新発見扱いして再提示**した。既発見照合不足の失敗。比較に使った6プロファイルは全員H>Mで、パイモン型の式に有利。短い「交換→確殺」の式は見つけやすいが、**見つけやすさ≠実戦強度**。繰り返した発見は独立した勝率証拠でない。

新候補を公表する前に、既存ノート・既発見候補・既存定石・失敗した反例・対照モデルを照合する。目立つコンボが何度も現れる場合、候補プール・相手プロファイル・評価指標の偏りを疑う。

## 7. 運用する評価指標と証拠水準

概念的な環境期待勝率：
W(T) = Σ_e [p(e) × P(win | T, e, 自他ステータス・装備・先攻系列)]

ただし**実際のp(e)、条件付き勝率、原作完全再現モデルは現時点で揃っていない**。架空の数値を入れた順位は作らない。

| 軸 | 評価内容 |
|---|---|
| 勝ち筋の論理 | 何をもって勝つか。確殺は条件付きか |
| 初動耐性 | 敵先手・自先手、1T停止、初手不発時の分岐 |
| メタ対面 | よく遭遇する構成群への勝敗。稀少型は別枠 |
| 再現性 | DP・限定所持・装備・アシスト・レベル |
| エンジン信頼度 | 図鑑式だけ／原作一部ログ／原作主経路照合済／未判定 |
| 新規性と対照 | 既発見・既存の単純な定石との比較 |

**現時点の結論**：優秀な構築探索の目的は「式の美しいコンボを列挙すること」ではなく、「現実の相手に対して勝ち筋が通り、共通の負け筋が少なく、使用可能な候補を発見・比較すること」。**「強い理由を探すだけでなく、負ける理由を積極的に探す」。**
