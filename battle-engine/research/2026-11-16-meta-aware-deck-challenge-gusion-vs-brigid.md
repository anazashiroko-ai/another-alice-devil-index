# 2026-11-16 「負ける理由」を先に探す最強テーブル考察（仮説段階）

**記録区分：** マリコの1T先攻じゃんけん／メタの指摘に基づく、図鑑能力文の論理検査。原作模擬戦の新規一括試行はしていない。原作勝率・決定的な最強順位は未判定。

## I. 比較する17DP編成

**基準B（既知強豪の制圧型）**：1T ◎春を喜ぶブリギット2 / 2T 賢者の火・フルカス4 / 3T ニコラス・レミ7 / 4T シェミハザ3 / 5T ウァサゴ1 / 6T 空欄 = **17DP**。ニコラス・レミの同一テーブル闇属性禁止を満たす。春が初手に先行すると敵1T札を阻止し次T先攻確保、フルカスで2T・3T札を消滅、レミで3T・4T札を消去・敵攻撃1、シェミハザが敵HPを旧守備、敵守備を旧攻撃力へ変更。レミで敵攻撃力を1にしていればシェミハザで敵守備1となる筋。**自動確殺ではなく、自分の攻撃力・生存・妨害時系列が必要**。レミの3Tは自分も攻撃できない。フルカスが自守備／HP30%減を伴う点に注意。

**挑戦A（攻撃特化の複線型）**：1T グシオン4 / 2T マシュー・ホプキンス3 / 3T 党首の威光を放つベレト4 / 4T 終わりなき夜・ビフロンス3 / 5T ○ファリニシュ2 / 6T ウァサゴ1 = **17DP**。明示属性排他なし、同一デビル重複なし、遅延指定なし。1T攻撃型グシオンの高倍率で即死狙い。初手で倒せない相手には2Tマシュー→3Tベレトで敵魔力1→守備約0（丸め境界未確認）を狙う。ただし1T→2Tと遅いため、既知の1Tマシュー→2Tベレトより隙が大きい。4Tビフロンスは敵現T札消去と通常攻撃後×1.5追撃、5Tファリニシュで現T消滅・自HP+20%。攻撃型の構築仮定であり、装備ステータス配分の試算は未実施。

## II. 対面別の負け筋（実戦の勝敗と混同禁止）

| 想定相手 | 基準Bの脆弱性 | 挑戦Aの脆弱性 |
|---|---|---|
| 1Tマシュー→2T党首ベレト | 1Tマシューに先を取られると春が阻止され、次T先攻保証を失う。2Tベレトに2Tフルカスを先手で阻止され得る。 | マシューが先ならグシオン停止。2Tマシューを先手で止められると3Tベレトも遅い。 |
| 1T攻撃盛りグシオン | 敵グシオンが先に発動すれば、春はその既発動効果を遡及して無効にしない。攻撃を受けて1Tで死ぬ可能性。 | 双方火力・攻撃順で早期決着。確実な防御／妨害にはならない。 |
| 1Tプロセルピナ | 敵が先なら、2Tフルカス枠を書き換えられ、制圧連鎖が崩れる可能性。 | 敵が先なら2Tマシューを書き換えられる。一方1Tグシオンが通って攻撃前に生存できれば即時決着筋は残る。 |
| 1Tネモフィラ | スクルドを含まないため、先にネモフィラが通ると2Tを交換される危険。 | 同様にネモフィラへの対処なし。 |
| 1Tパイモン | 春が先なら初手阻止可。パイモンが先で魔力が低いとHPを危険な値に書き換えられ得る。 | 攻撃特化で魔力を極端に削ると、パイモン先手時にHPを魔力へ交換され即落ちしやすい。対パイモンまで考えるなら魔力の最低ラインが問題となり、グシオン火力とトレードオフ。 |

## III. 第三の候補が棄却される例

「1T春2→2T赤フォルター4→3Tオドラデク3」（9DP）は、春が先手なら2T先攻を取れ、赤で敵装備を無効にし3T札を消し、オドラデクで攻守1にするため一見強い。しかし**敵の2T札の発動そのものは赤が阻止しない**。敵が2Tに賢者の火・フルカスを置けば、こちらの3Tオドラデクを消滅させられる。従って「春→フルカス」のように2Tと3Tをまとめて止める定石に比べ、2Tへの隙が残る。これを盲点として棄却／再設計する。単に二つの強い連携を足すだけでは最強候補にならない。

## IV. 今後の評価設計

「万能最強」はメタ頻度（構成の事前分布）、先攻抽選、装備型、法規制などの合法性に依存する。局所的に勝つ筋だけでなく**各相手がこちらの最も弱い分岐を突いた時**の損失を先に調べる。原作再現検証を終えていないモデル出力に実戦勝率を擬装しない。基準Bは現役既知の強豪である一方、挑戦Aがそれを超えたという証拠はまだない。
