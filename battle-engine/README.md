## 使い方

1. `index.html` を開く。外部ライブラリなしの単一HTMLで動作します。
2. シロコと対戦相手のデビル6枠・能力値・先攻順を編集します。
3. 図鑑からデビル名を検索して配置できます。図鑑の読み込みに失敗した場合、`devils.json` をダウンロードして画面から読み込めます。
4. **数値＋発動順**では、未実装能力が出ると判定不能で停止します。**発動順のみ**は数値と勝敗を計算しません。
5. 対戦設定は画面のJSON出力／読み込みで保存・再現できます。

## 現在の研究状況

- デビル図鑑396体を監査対象とし、**125種類に数値・状態処理モデル**があります（実戦数値の完全一致を意味しません）。
- 2026-11-13版004.6ではアブンディア、アバドン、マシュー・ホプキンス、党首の威光を放つベレト、春を喜ぶブリギット、謹賀新年・アリエル、ディアーナの説明文モデルを追加。雪崩を切り裂くルシファーは**（仮）**を明記して計算可能に。ネモフィラは意図的に保留。
- 2026-11-12版004.5では、ヘクセンナハト再発動、スクルド再判定、ウヴァル系と装備無効化系の違い、プロセルピナによる未来枠変更、3ターン魔力戦、ジャック・ロレ、フルーレティ等の検証結果を反映。
- 開発環境では既存回帰テスト**153件**と今回の追加テスト**16件**の計**169件通過**。公開リポジトリの既存004.5テスト群も保存。
- 現行画面は004.6。実戦確認済み・説明文モデル・（仮）・未実装を区別。説明文モデルでも原作の完全再現を保証しない。
- 依然として、魔力戦の公式ダメージ式、反射／混乱の競合、未実装の各種デビルなどは未確定。
- 原作由来の名称・能力説明を参照する場合も、**公式仕様・公式の計算式が解明されたと主張しません**。

## リポジトリ構成

```text
battle-engine/
├── index.html                       # 実行可能な単体HTML (004.6)
├── legacy.html                      # ES5変換を用いた旧端末用単体HTML
├── audit.html                       # 396体の実装・保留監査画面
├── README.md                        # この文書
├── src/
│   ├── kei_unified_engine_v0_4_6.js # 現行004.6のエンジン
│   ├── kei_unified_engine_v0_4_5.js # 旧004.5のエンジン
│   └── kei_battle_engine_v0_2.js    # 既存ダメージ推定基盤
└── tests/
    ├── test_kei_unified_engine_v0_4_5.js
    └── test_kei_0046_additions.js  # 追加能力・保留規則の回帰テスト
```

### ソースをローカルで試験する

リポジトリのルートから（Node.jsのみ、追加パッケージ不要）：

```bash
node battle-engine/tests/test_kei_unified_engine_v0_4_5.js
node battle-engine/tests/test_kei_0046_additions.js
```

`index.html` には動作に必要なJSを埋め込んでいるため、GitHub Pagesでは `src/` のファイルを別読み込みしません。HTMLの単独利用と、ソースの編集・回帰試験は別の用途です。

## データと公開範囲

公開デビル図鑑（`another-alice-devil-index/dist/devils.json`）は**読み込み専用**です。戦闘設定JSONは利用者自身が保存する方式で、サーバーへの自動保存・ログ送信は行いません。

このページは非公式の共同研究用試作であり、ゲーム開発元とは無関係です。実際の対戦結果やゲーム内データへの反映機能はありません。
