## 使い方

1. `index.html` を開く。外部ライブラリなしの単一HTMLで動作します。
2. シロコと対戦相手のデビル6枠・能力値・先攻順を編集します。
3. 図鑑からデビル名を検索して配置できます。図鑑の読み込みに失敗した場合、`devils.json` をダウンロードして画面から読み込めます。
4. **数値＋発動順**では、未実装能力が出ると判定不能で停止します。**発動順のみ**は数値と勝敗を計算しません。
5. 対戦設定は画面のJSON出力／読み込みで保存・再現できます。

## 自動同期パイプライン

- **原作図鑑**：`dist/devils.json` が能力文・属性・DPの出典。実装から原作説明文を自動で上書きしない。
- **実装状態**：`dist/engine-status.json` はエンジンの `D` から生成。図鑑の各詳細画面はこれを読み込み、実装済み／主効果の部分実装／未実装を表示する。
- **同じ計算本体**：`scripts/sync-engine.cjs` は `battle-engine/src` を使い、通常版HTMLと旧端末向けHTMLを同時に生成。簡易版には Babel・core-js を使う。旧端末の互換性は実機検証が別途必要。
- **自動実行**：`.github/workflows/engine-sync.yml` がソース・図鑑更新時に生成・検査・出力反映する。GitHub Actions失敗時は古い公開物が残るため、ビルド成功の確認が必要。
- **記述モデルと原作完全再現は別**。不明な追加効果は未解明として保持する。

## 004.8大規模モデル実装（2026-11-13）

- **図鑑396体／計算・状態モデルあり387体／保留9体**。004.7の140体から、004.8で**247体の「主効果・部分モデル」**を追加した。247体のうち、全例外・全発動順・原作一致まで確認したものはない。「モデルあり」を「全能力完全実装」と読み替えないこと。
- 登録定義は `src/kei_batch_rules_0048.js`（図鑑IDを持つ248候補）。このうち**247モデルをエンジンに接続**。効果の時系列や式が大きく未確定の **#94 アラストル** の1候補は登録草案に残すが、**実装数に計上しない**。ほかの保留8体（うちアウデベルト・◎シュガールは戦闘計算対象外）もモデルなし。
- 主な共通処理として、ターン限りの補正解除、攻撃ダメージからの追加ダメージ、回避・混乱・反射、確率と乱数シード、継続処理、一部の装備・デビルテーブル参照、外部数値入力（順位・アシスト人数・装備・GOLD等）、体力1での復活を組み込んだ。
- **注意：モデルは発動条件・例外・攻撃前後のイベント・外部入力・一時補正の重畳で原作と不一致があり得る**。たとえば「隠し条件」「複数条件の競合」「魔力戦ダメージ式」「未来枠交換」「即死と再発動の優先順位」には未検証が残る。敵攻撃が負の守備力に対して与える通常ダメージは、公式式が不明な場合に計算不能で止める。
- 外部値が必要なモデルは追加条件JSONを手入力。未指定の値は架空値で補わず、必要に応じて「判定不能」で停止する。現行のブラウザ版は**通常画面004.8**に更新した。旧端末向け`legacy.html`も**004.8へ自動変換済み**で、247体の新規部分モデルを同じ計算ソースから搭載。ただし古い実機での動作確認は未完了。
- `tests/test_kei_0048_batch.js` で**247体の発動スモーク試験＋12種類の個別検証＝252検査**を定義。V8の隔離実行環境では266検査を実行して成功した。**Node.js実行環境および旧端末実機で全テストを再実行した実績ではない**。旧スイートを各対応版で別途V8上で実行し、004.5で159／159、004.6で13／13、004.7で17／17を確認した。旧004.7スイートを新004.8で動かすと、モデル数・グシオン保留の旧仕様を固定した2件は意図的に不一致（残り15件は通過）。

- **公開WebでのスモークQA：** 004.8の表示、図鑑396体の読込、モデル内訳（公開ブラウザで前回確認した旧集計240／16（現行は247／9。最新の数値モードは別途ブラウザ検証が必要））、検索・枠編集、6ターン**発動順追跡モード**の完了、独立監査ページの読込を確認した。**このブラウザ試験は数値＋発動順モードの全戦闘検証ではない**。Gusionが編集画面で誤って「旧試作」と表示されるラベルも、004.8部分モデル表示に修正済み。

**区分別集計**：実戦規則反映8、既存部分暫定5、既存記述モデル104、旧試作23、004.8主効果・部分モデル247、未実装9（合計396）。

### ソースをローカルで試験する

```bash
node battle-engine/tests/test_kei_unified_engine_v0_4_5.js
```

## データと公開範囲

公開デビル図鑑（`another-alice-devil-index/dist/devils.json`）は**読み込み専用**です。戦闘設定JSONは利用者自身が保存する方式で、サーバーへの自動保存・ログ送信は行いません。

このページは非公式の共同研究用試作であり、ゲーム開発元とは無関係です。実際の対戦結果やゲーム内データへの反映機能はありません。
