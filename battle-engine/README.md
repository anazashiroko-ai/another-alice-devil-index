## 使い方

1. `index.html` を開く。外部ライブラリなしの単一HTMLで動作します。
2. シロコと対戦相手のデビル6枠・能力値・先攻順を編集します。
3. 図鑑からデビル名を検索して配置できます。図鑑の読み込みに失敗した場合、`devils.json` をダウンロードして画面から読み込めます。
4. **数値＋発動順**では、未実装能力が出ると判定不能で停止します。**発動順のみ**は数値と勝敗を計算しません。
5. 対戦設定は画面のJSON出力／読み込みで保存・再現できます。

## 004.8大規模モデル実装（2026-11-13）

- **図鑑396体／計算・状態モデルあり372体／保留24体**。004.7の140体から、004.8で**232体の「主効果・部分モデル」**を追加した。232体のうち、全例外・全発動順・原作一致まで確認したものはない。「モデルあり」を「全能力完全実装」と読み替えないこと。
- 登録定義は `src/kei_batch_rules_0048.js`（図鑑IDを持つ240候補）。このうち**232モデルをエンジンに接続**。効果の時系列や式が大きく未確定の **#6 ブエル／#38 デカラビア／#94 アラストル／#102 ○オスタル／#215 ◎誕生と消滅／#294 ルナ・スピアーナ／#309 フェンリル／#340 クエレブレ＆シャナ** の8候補は登録草案に残すが、**実装数に計上しない**。ほかの保留16体もモデルなし。
- 主な共通処理として、ターン限りの補正解除、攻撃ダメージからの追加ダメージ、回避・混乱・反射、確率と乱数シード、継続処理、一部の装備・デビルテーブル参照、外部数値入力（順位・アシスト人数・装備・GOLD等）、体力1での復活を組み込んだ。
- **注意：モデルは発動条件・例外・攻撃前後のイベント・外部入力・一時補正の重畳で原作と不一致があり得る**。たとえば「隠し条件」「複数条件の競合」「魔力戦ダメージ式」「未来枠交換」「即死と再発動の優先順位」には未検証が残る。敵攻撃が負の守備力に対して与える通常ダメージは、公式式が不明な場合に計算不能で止める。
- 外部値が必要なモデルは追加条件JSONを手入力。未指定の値は架空値で補わず、必要に応じて「判定不能」で停止する。現行のブラウザ版は**通常画面004.8**に更新した。旧端末向け`legacy.html`は**004.7のまま**で、今回の232体追加はまだ移植していない。
- `tests/test_kei_0048_batch.js` で**232体の発動スモーク試験＋7種類の個別検証＝239検査**を定義。V8の隔離実行環境では239検査を実行して成功した。**Node.js実行環境および旧端末の実機で全テストを再実行した実績ではない**。既存004.5～004.7の186件も今回のV8検査では再実行していない。

## 現在の研究状況

- デビル図鑑396体を監査対象とし、**140種類に数値・状態処理モデル**があります（実戦数値の完全一致を意味しません）。
- 2026-11-13版004.7では、説明文に基づく単純な数値処理を15体追加。既存82件の記述モデルを97件へ拡張し、**140体がモデルあり／256体が保留**。通常版と旧端末版の両方に反映した。テストコードは追加したが、実機・原作との完全一致は未保証。グシオン系3体の図鑑能力説明は変更していない。通常グシオンは当ターン回避と一時補正の処理、派生2体は初期セットデビルの属性数別の能力値変化が未実装のため保留。監査台帳の旧表示「特殊状態・魔力戦・ダメージ処理が未完成」は「回避」単語に反応した分類文の誤りであり、グシオンの魔力戦能力を意味しない。
- 2026-11-13版004.6ではアブンディア、アバドン、マシュー・ホプキンス、党首の威光を放つベレト、春を喜ぶブリギット、謹賀新年・アリエル、ディアーナの説明文モデルを追加。雪崩を切り裂くルシファーは**（仮）**を明記して計算可能に。ネモフィラは意図的に保留。
- 2026-11-12版004.5では、ヘクセンナハト再発動、スクルド再判定、ウヴァル系と装備無効化系の違い、プロセルピナによる未来枠変更、3ターン魔力戦、ジャック・ロレ、フルーレティ等の検証結果を反映。
- 公開リポジトリで定義されたテストケースは、004.5回帰テスト**156件**（通常の`check(...)` 74件＋`SOURCE_RULES` 82件から自動生成される82件）と004.6追加テスト**13件**、004.7の数値追加テスト**17件**の、合計**186件**です（004.6時点は169件）。これは定義数の集計であり、今回の照合でNode.js上の全テストを再実行したPASS件数ではありません。
- 以前の研究記録には「004.5で153件から159件PASSに増加」「004.6で153件＋16件＝169件PASS」という当時の実行報告があります。これらの数え方と、現行公開コードの**156件＋13件**という内訳は一致しません。過去の報告は履歴として維持し、再現済みの公開テスト実績と混同しません。
- 現行画面は004.7。実戦確認済み・説明文モデル・（仮）・未実装を区別。説明文モデルでも原作の完全再現を保証しない。
- 依然として、魔力戦の公式ダメージ式、反射／混乱の競合、未実装の各種デビルなどは未確定。
- 原作由来の名称・能力説明を参照する場合も、**公式仕様・公式の計算式が解明されたと主張しません**。

